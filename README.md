# 麓商联商户积分系统

商户端与运营后台为**两个独立页面**，共用同一份数据。积分板块严格按《麓商联商户积分体系第一年试行方案》分为三大板块：**公益捐赠值 / 商圈共生值 / 社区参与值**。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `index.html` | **商户端**（扫码进入的页面），首页 / 参与 / 兑换 / 明细 |
| `admin.html` | **运营后台**（独立页面，不对外开放） |
| `store.js` | 两个页面共用的数据层（板块定义与积分规则、积分发放、存储） |
| `app.js` | 商户端逻辑 |
| `admin.js` | 运营后台逻辑 |
| `styles.css` | 两端共用的样式（配色等全部集中在 `:root` 变量里） |
| `fx.js` | 标题粒子效果（粒子缓缓汇聚成文字） |

## 快速预览

同一文件夹下双击 `index.html` 打开商户端，双击 `admin.html` 打开后台。

> 建议用本地服务器或正式域名访问（例如把整个文件夹上传到网站空间）。部分浏览器直接双击 `file://` 打开时，两个页面的本地数据不互通，用服务器访问即可正常联动。

## 视觉风格

参照「麓客热汗圈 LETS SWEAT」浅色版：米白底、墨黑描边的轻微倾斜卡片（带橙色编号角标）、荧光绿马克笔底条、橙红点缀、粗黑中文大标题、窄体数字、等宽字距英文标签、错位色块阴影按钮、荧光绿斜向跑马灯条与点阵装饰。

- **粒子效果**：首页主标题、后台各页标题，以及重点数据（可用积分、本月获得、年度贡献值、三大板块分值、商圈面板三项指标、后台统计数字）都会在滚动进入画面时由粒子缓缓汇聚成字；数值变化（如审核发放后）会重新汇聚。
- **其他动效**：卡片 / 列表 / 区块标题滚动依次滑入，贡献条与等级进度条从 0 生长，荧光绿马克笔底条“划”出，积分变化时积分卡飘出 +N / -N，兑换与申报成功迸发彩纸，商圈动态带实时闪烁圆点。
- 系统开启“减少动态效果”时，以上动效自动关闭。
- 商户端按微信小程序画面呈现：顶部导航栏 + 右上角胶囊按钮、底部 TabBar、底部弹出式表单。电脑打开时显示在手机框中，手机打开时全屏显示。
- 调整配色只需修改 `styles.css` 顶部的 `:root` 变量。

## 三大板块与积分规则

| 板块 | 记录内容 | 怎么积分 | 核验依据 |
| --- | --- | --- | --- |
| 公益捐赠值 | 通过麓湖社区发展基金会等指定公益渠道完成的捐赠 | 每捐赠 100 元计 10 分（最低统计单位 100 元，不足部分年度内累计）；物资 / 服务捐赠按确认价值每 100 元计 10 分；同一笔捐赠只计一个账户，退款同步撤回 | 基金会到账记录、捐赠证书或公益票据 |
| 商圈共生值 | 参与调研、商学院、商圈共创及联合活动 | 有效问卷每份 20 分，重点调研 30–100 分；商学院到场 30 分、完成系列课程 +50 分、分享嘉宾 100 分；报名不计分，完成后发放 | 系统记录、现场签到及项目确认 |
| 社区参与值 | 参加社区活动、社区议事、志愿服务和社区共建项目 | 按活动要求完成计分；共建项目（收捐点、物资支持）按负责人确认计分；仅作参与记录，不作考核 | 活动签到、现场照片及负责人确认 |

## 商户端

**首页**
- 积分卡：可用积分、本月累计获得、当前年度等级
- 年度贡献值：按**三大板块**（公益捐赠值 / 商圈共生值 / 社区参与值）分段展示
- **三大板块 · 怎么积分**：三张规则卡，逐条列出该板块的记录内容、积分标准与核验依据，并显示本店在该板块的累计分
- **商圈动态面板**：标题默认“圈里新鲜事”，只显示月份、不写商圈名称；含三项指标与公告。内容全部来自后台「商圈面板」，商户端不可编辑
- **本月可参与**：本月开放的参与内容，每项带板块标签、参与形式（线上参与 / 线下市集 / 公益捐赠 / 商学院课程 / 社区活动）、积分值、核验方式
- **本月兑换权益**：直接列出权益名称、所需积分、剩余份数，并标注“积分足够，可立即兑换”或“还差 X 分”
- 积分明细：最近记录

**其他页**
- 参与：全部本月参与内容，可按三大板块筛选
- 兑换：积分商城完整卡片
- 明细：该门店全部积分流水（每条标注所属板块）
- 底部「切换 / 重新绑定门店」：演示时可切换不同商户查看

## 运营后台（admin.html）

| 栏目 | 功能 |
| --- | --- |
| 审核中心 | 待审核入驻申请（通过 / 拒绝）、积分申报审核（显示所属板块、查看材料、改发放分值、通过发放 / 退回） |
| 商户管理 | 全部商户档案，含可用积分与**三大板块分项**、年度贡献与等级；可手动新增商户 |
| **商圈面板** | 配置商户端首页商圈动态：面板名称、展示月份、三项指标（名称/数值/单位）、公告的新增 / 编辑 / 删除 |
| 积分任务 | 新建 / 编辑 / 删除本月参与内容，设置所属板块、参与形式、积分值、核验方式、开放或停用 |
| 权益兑换 | 新增 / 编辑 / 上下架 / 删除权益（名称、说明、所需积分、库存、分类） |
| 兑换订单 | 商户兑换申请履约流转：待处理 → 处理中 → 已完成 |
| 数据统计 | 发放 / 消耗 / 通过率、**三大板块贡献分布**、三大板块积分规则说明、商户贡献排行 |

## 关键逻辑

- **积分发放**：审核通过时按确认分值同时更新可用积分、对应板块分项与年度贡献值，并写入流水，商户端刷新即可看到。
- **兑换规则**：只扣可用积分，年度贡献值不扣减；兑换成功自动生成后台兑换订单并扣减库存。
- **贡献值计算**：年度贡献值 = 三大板块分项之和，等级按 200 / 500 / 1000 / 2000 分档。
- **捐赠累计**：捐赠申报审核时，若不改动分值，系统把上次不足 100 元的余额并入本次金额折算，剩余部分继续年度累计；审核中心「最近处理」可对已发放记录**撤回积分**（对应退款撤回）。
- **数据存储**：浏览器 localStorage，键名 `lsl-points-db-v5`。需要恢复初始演示数据时，在控制台执行 `LSL.reset()` 或清空该键。

## 正式运营前的技术说明

当前为纯前端演示版本，数据存在各自浏览器本机。多商户正式运营需要补充：服务器共享数据库、短信验证码登录、图片/凭证对象存储、管理员账号与权限、兑换履约通知，以及基金会捐赠数据的月度对账导入。
