# 麓商联商户积分系统（演示版）

商户端（手机端 H5，后期接入麓湖+ 小程序）与运营后台为**两个独立页面**，共用同一份数据。积分板块严格按《麓商联商户积分体系第一年试行方案》分为三大板块：**公益捐赠值 / 商圈共生值 / 社区参与值**。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `index.html` | **商户端**（手机端 H5）：首页 / 参与 / 商学院 / 兑换 / 我的 |
| `admin.html` | **运营后台**（独立页面，需账号登录，不对外开放） |
| `store.js` | 两个页面共用的数据层：板块规则、积分发放、登录会话、门店绑定、后台账号权限 |
| `app.js` | 商户端逻辑（含 5 套视觉风格切换） |
| `admin.js` | 运营后台逻辑 |
| `fx.js` | 动效：粒子汇聚成字、滚动进场、彩纸礼花 |
| `styles.css` | 基础样式（默认「热汗」风格 + 运营后台） |
| `themes.css` | 商户端另外 4 套视觉风格 |
| `fonts/` | 像素风格使用的 Press Start 2P 字体（SIL OFL 开源授权，见 `fonts/PressStart2P-OFL.txt`） |
| `docs/` | 第一版功能清单 |

## 三大板块与积分规则

| 板块 | 记录内容 | 怎么积分 | 核验依据 |
| --- | --- | --- | --- |
| 公益捐赠值 | 通过麓湖社区发展基金会等指定公益渠道完成的捐赠 | 每捐赠 100 元计 10 分（不足部分年度内累计）；物资 / 服务按确认价值折算；退款同步撤回 | 基金会到账记录、捐赠证书或公益票据 |
| 商圈共生值 | 参与调研、商学院、商圈共创及联合活动 | 有效问卷 20 分，重点调研 30–100 分；商学院到场 30 分、系列课程 +50 分、分享嘉宾 100 分；报名不计分 | 系统记录、现场签到及项目确认 |
| 社区参与值 | 社区活动、议事、志愿服务和共建项目 | 按活动要求完成计分；共建项目按负责人确认计分 | 活动签到、现场照片及负责人确认 |

## 商户端

- **登录**：手机号 + 短信验证码（60 秒限发、每日限次），30 天免登录、每次打开自动续期；换手机或清缓存后重新验证，账号和积分不变。游客可先浏览介绍、活动、商学院，参与 / 报名 / 兑换时再要求登录。
- **绑定门店**：首次登录后选择门店，输入**门店绑定码**立即生效，或**提交审核**（可传门头照）；门店不在列表可**申请入驻**。一个手机号可绑定多家门店，积分记在门店名下。
- **首页**：积分卡、轮播图（后台换图）、三项统计数据（后台可改、点击跳转）、快捷入口（关于我们 / 商学院 / 我的数据 / 本月活动）、年度贡献值、三大板块怎么积分、商圈动态、本月活动、商学院近期课程、兑换权益、工作人员、**合作意向留资表单**。
- **参与**：本月活动，按三大板块筛选，完成后上传凭证申报。
- **商学院**：本月课程（报名 / 取消，到场签到后自动发分）、导师、往期回顾。
- **兑换**：积分商城，显示“积分足够”或“还差 X 分”。
- **我的**：我的数据（积分构成、排名、参与次数、等级进度）、积分明细、我的申报 / 兑换 / 报名、门店成员（店长可查看绑定码、移除店员）、切换门店、关于我们、视觉风格、退出登录。
- **关于我们**：麓商联介绍、“遇到问题找谁”（选事项 → 对应工作人员，一键拨号 / 复制微信号）、工作人员展示、合作留资。

## 运营后台（admin.html）

| 栏目 | 功能 |
| --- | --- |
| 审核中心 | 新店入驻申请、**门店绑定审核**、积分申报审核（改分值、通过发放 / 退回）、已发放积分撤回 |
| 商户管理 | 商户档案与三大板块分项；门店成员（设为店长 / 店员、强制下线、移除）；查看与重置绑定码 |
| 积分任务 / 权益兑换 / 兑换订单 | 活动、权益的增删改与上下架；订单 待处理 → 处理中 → 已完成 |
| 商学院 | 课程（时间、地点、名额、签到分值）、报名名单与**签到发分**、导师、往期回顾（含照片） |
| 内容管理 | 首页轮播图（上传、排序、跳转）、**首页三项统计数据**（系统自动统计 / 手动填写、点击跳转目标）、商圈面板与公告、关于我们与“遇到问题找谁” |
| 工作人员 | 新增 / 编辑 / 排序 / 隐藏 / 删除，照片或头像底色，负责事项与联系方式 |
| 合作留资 | 留资列表、跟进状态（未联系 / 已联系 / 已合作 / 无效）、备注、导出 CSV |
| 数据统计 | 发放 / 消耗 / 通过率、用户与报名、三大板块分布、商户排行 |
| **用户管理**（仅超级管理员） | 管理麓湖运营人员账号：新增用户、编辑、**重置密码**（生成新密码，首次登录强制修改）、停用 / 启用、**删除用户**；至少保留一名超级管理员，不能删除或停用自己；**操作日志** |

所有后台用户都可在右上角修改自己的密码。

## 关键逻辑

- **积分发放**：审核通过 / 课程签到时，同时更新可用积分、对应板块分项与年度贡献值，并写入流水。
- **兑换规则**：只扣可用积分，年度贡献值不扣减；兑换成功自动生成订单并扣减库存。
- **贡献值计算**：年度贡献值 = 三大板块分项之和，等级按 200 / 500 / 1000 / 2000 分档。
- **数据存储**：演示版存在浏览器 localStorage，键名 `lsl-points-db-v6`。恢复初始数据：后台右上角「恢复演示数据」（超级管理员），或控制台执行 `LSL.reset()`。

## 正式运营前的技术说明

当前为纯前端演示版本：验证码固定为 `1234`，密码校验与会话都在浏览器本地完成，**不能直接用于正式运营**。正式版需要：

- 服务端与共享数据库；短信平台下发验证码（短信签名使用麓湖资质）；
- 会话与权限全部在服务端校验，后台密码用 bcrypt / argon2 存储；
- 图片 / 凭证对象存储；兑换、审核结果的短信通知；基金会捐赠数据月度对账导入；
- 使用麓湖已备案域名下的子域名 + HTTPS，后期在麓湖+ 小程序配置业务域名后接入，商户账号以手机号对应、无需重新注册。
