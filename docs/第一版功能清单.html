一、商户端功能

标 新增 的是会上新提的需求，其余为演示版已有、正式版完善
1. 登录与注册
  • 手机号 + 短信验证码登录；登录一次 30 天内免登录
  • 首次进入：先看介绍 → 填写门店信息（可传门头照）→ 身份确认 → 成为会员
  • 再次进入：自动识别，直接进入个人积分
  • 游客可先浏览介绍、活动、商学院；参与活动、兑换时再要求登录
首次 扫码 → 关于我们 → 手机号登录 → 选择 / 填写门店 + 照片 → 身份确认 → 成为会员
再次 扫码 → 自动登录 → 首页看到自己的积分
2. 首页
  • 图片展示区：轮播图，后台自助换图
  • 积分卡：可用积分、本月获得、年度等级（登录后显示）
  • 三项统计数值：数值后台可改，点击跳转到对应页面
  • 三大板块怎么积分、本月活动、本月可兑换权益
  • 一级入口：关于我们 / 商学院 / 数据，入口精简，一步直达
3. 活动参与与积分申报
  • 本月活动列表，按公益捐赠 / 商圈共生 / 社区参与三大板块筛选
  • 完成后提交申报、上传凭证，审核通过自动发分
4. 积分兑换
  • 权益列表，显示所需积分、剩余份数、“还差多少分”
  • 兑换后扣积分、扣库存，生成订单，商户可查看进度
5. 个人中心 · 我的积分
  • 积分明细、我的申报、我的兑换、门店信息
6. 数据板块
  • 商户看自己的：积分构成、参与活动次数、年度等级进度
7. 商学院
  • 导师：照片、头衔、擅长方向、一句话介绍
  • 往期回顾：现场照片、视频、按场次翻看
  • 本月课程：时间、主题、导师、剩余名额，在线报名；到场签到后按规则发分
8. 关于我们
  • 麓商联介绍
  • “遇到什么事找谁”：选事项 → 显示对应联系人，可一键拨号或加微信
9. 工作人员展示 新增
  • 工作人员卡片：照片、姓名、职务、负责事项、联系方式（电话 / 企业微信二维码）
  • 和“关于我们”的联系人打通：同一份人员资料，后台维护一次
10. 合作意向留资（页面底部） 新增
  • 页面最下方“聊一次合作”表单：姓名、公司 / 品牌、手机号、合作类型、留言
  • 提交前勾选同意隐私说明；防重复提交、防刷

二、运营后台功能

给积分系统的运营人员用，日常内容都能自己改，不用找技术
1. 审核中心
  • 入驻 / 注册审核，积分申报审核（可改分值、退回、撤回已发积分）
2. 商户管理
  • 商户档案、积分与三大板块分项、门店成员（店长 / 店员）、改绑手机号
3. 活动与积分任务
  • 新建 / 编辑 / 停用活动，设置板块、形式、分值、核验方式
4. 权益兑换与订单
  • 权益上下架、库存；订单流转：待处理 → 处理中 → 已完成
5. 内容管理 新增统计数据修改
  • 首页统计数值：名称、数值、单位、点击跳转目标；可选“系统自动统计”或“手动填写”
  • 图片展示区、商圈动态与公告、关于我们文案
  • 商学院：导师、往期回顾、课程、报名名单与签到
6. 工作人员管理 新增
  • 新增 / 编辑 / 排序 / 隐藏工作人员，设置负责事项
7. 合作留资管理 新增
  • 查看、标记跟进状态（未联系 / 已联系 / 已合作）、导出 Excel；有新留资时提醒
8. 数据统计与账号权限
  • 积分发放 / 消耗、三大板块分布、商户排行、活动参与情况
  • 多个后台账号，按角色分权限，关键操作留日志

三、还需要对齐的事项

绿色字是我们的建议，确认或修改即可
1
首页三项统计数据：手动填写，还是系统自动统计？
分别是哪三项？每项点击后跳到哪个页面？
建议：能自动统计的自动算，后台保留“手动覆盖”开关，方便对外展示时调整。
2
工作人员展示：展示哪些人、哪些信息？
放在“关于我们”里还是单独入口？联系方式公开到什么程度（个人手机 / 工作电话 / 企业微信）？
建议：放在“关于我们”里，联系方式用工作电话或企业微信二维码，不公开个人手机。
3
合作留资：需要哪些字段？谁来接收、怎么通知？
合作类型有哪些选项？新留资通知谁：短信、邮件，还是只在后台看？
建议：后台查看 + 给指定负责人发短信提醒。
4
登录方式：只用短信验证码，还是加“本机号码一键登录”？
一键登录在网页里需接入运营商服务，只在手机流量下可用，按次收费；短信签名用哪个公司名称、谁提供资质。
建议：第一版只用短信验证码，费用低、兼容性好。
5
注册要填什么？照片是否必填？
门店名称、业态、联系人、铺位号……哪些必填？门头照 / 产品照是否必须上传？
建议：照片选填，必填项越少，注册率越高。
6
怎么确认“这个人确实是这家店的”？
运营人工审核 / 每家店一个专属二维码 / 邀请码，选哪种？门店清单由谁提供？
建议：每家店发一个专属二维码，扫码即绑定；清单外的新店走人工审核。
7
游客（未注册）能看到哪些内容？
首页、商学院、关于我们是否对所有人开放？
建议：介绍类内容全开放，积分、报名、兑换需登录。
8
商学院报名：站内表单还是跳外部链接？
是否限名额？报名后要不要提醒？到场签到用什么方式（现场扫码 / 工作人员核销）？
建议：站内报名 + 现场扫码签到，签到后自动发 30 分。
9
积分规则还缺的两点：年底是否清零？等级有什么权益？
年度贡献值、可用积分到年底分别怎么处理？200 / 500 / 1000 / 2000 四个等级各对应什么？
10
消息通知：审核结果、兑换进度、课程提醒，用什么方式通知商户？
网页无法直接发微信消息。
建议：重要节点发短信，其余在“个人中心”里显示提醒。
11
视觉与图片规范
按商联调性改版，范围是全站；验收人和修改轮次；轮播图尺寸、张数上限、上传是否需要审核；图片和文案由谁提供。
建议：设计稿含两轮修改；轮播图统一 16:9，最多 5 张。
12
上线部署、排期与维护
使用麓湖已备案域名下的子域名（名称？谁解析？）；服务器开在麓湖的云账号下；短信与服务器费用归属；上线时间、试点门店；维护范围与响应时间。
