第一版功能清单

根据 11 月 10 日会议整理，列出第一版要做的功能点
商户端 10 个模块 运营后台 8 个模块 会上新增 3 项

零、第一版范围

先以手机端 H5 上线、跑通流程，后期接入麓湖+ 小程序
第一版做
  • 手机端 H5：适配手机屏幕，扫码或点链接进入，微信内、手机浏览器都能打开
  • 手机号 + 短信验证码登录，不依赖麓湖+ 账号
  • 商户端 + 运营后台，审核、兑换、活动由积分系统运营人员负责
  • 会上新增：后台改统计数据、工作人员展示、合作意向留资
后期规划
  • 接入麓湖+ 小程序：同一套页面放进麓湖+ 里打开
  • 与麓湖+ 账号打通，支持微信手机号快捷登录
  • 第一版以手机号作为账号标识，接入后商户账号和积分直接沿用，无需重新注册

一、商户端功能

标 新增 的是会上新提的需求，其余为演示版已有、正式版完善
1. 登录与注册
  • 手机号 + 短信验证码登录，验证码 60 秒限发、每日限次，防恶意刷取
  • 登录后 30 天免登录，每次打开自动续期；换手机或清缓存后重新验证，账号和积分不变
  • 首次进入：先看介绍 → 填写门店信息（可传门头照）→ 身份确认（运营审核或门店专属二维码）→ 成为会员
  • 再次进入：自动识别，直接进入个人积分
  • 游客可先浏览介绍、活动、商学院；参与活动、兑换时再要求登录
首次 扫码 → 关于我们 → 手机号登录 → 选择 / 填写门店 + 照片 → 身份确认 → 成为会员
再次 扫码 → 自动登录 → 首页看到自己的积分
2. 首页
  • 图片展示区：轮播图，后台自助换图
  • 积分卡：可用积分、本月获得、年度等级（登录后显示）
  • 三项统计数值：数值后台可改，点击跳转到对应页面
  • 三大板块怎么积分、本月活动、本月可兑换权益
  • 一级入口：关于我们 / 商学院 / 数据，入口精简，一步直达
3. 活动参与与积分申报
  • 本月活动列表，按公益捐赠 / 商圈共生 / 社区参与三大板块筛选
  • 完成后提交申报、上传凭证，审核通过自动发分
4. 积分兑换
  • 权益列表，显示所需积分、剩余份数、“还差多少分”
  • 兑换后扣积分、扣库存，生成订单，商户可查看进度
5. 个人中心 · 我的积分
  • 积分明细、我的申报、我的兑换、门店信息
6. 数据板块
  • 商户看自己的：积分构成、参与活动次数、年度等级进度
7. 商学院
  • 导师：照片、头衔、擅长方向、一句话介绍
  • 往期回顾：现场照片、视频、按场次翻看
  • 本月课程：时间、主题、导师、剩余名额，在线报名；到场签到后按规则发分
8. 关于我们
  • 麓商联介绍
  • “遇到什么事找谁”：选事项 → 显示对应联系人，可一键拨号或加微信
9. 工作人员展示 新增
  • 工作人员卡片：照片、姓名、职务、负责事项、联系方式（电话 / 企业微信二维码）
  • 和“关于我们”的联系人打通：同一份人员资料，后台维护一次
10. 合作意向留资（页面底部） 新增
  • 页面最下方“聊一次合作”表单：姓名、公司 / 品牌、手机号、合作类型、留言
  • 提交前勾选同意隐私说明；防重复提交、防刷

二、运营后台功能

给积分系统的运营人员用，日常内容都能自己改，不用找技术
1. 审核中心
  • 入驻 / 注册审核，积分申报审核（可改分值、退回、撤回已发积分）
2. 商户管理
  • 商户档案、积分与三大板块分项、门店成员（店长 / 店员）、改绑手机号
  • 移除店员后其登录立即失效，可强制下线、查看最近登录时间
3. 活动与积分任务
  • 新建 / 编辑 / 停用活动，设置板块、形式、分值、核验方式
4. 权益兑换与订单
  • 权益上下架、库存；订单流转：待处理 → 处理中 → 已完成
5. 内容管理 新增统计数据修改
  • 首页统计数值：名称、数值、单位、点击跳转目标；可选“系统自动统计”或“手动填写”
  • 图片展示区、商圈动态与公告、关于我们文案
  • 商学院：导师、往期回顾、课程、报名名单与签到
6. 工作人员管理 新增
  • 新增 / 编辑 / 排序 / 隐藏工作人员，设置负责事项
7. 合作留资管理 新增
  • 查看、标记跟进状态（未联系 / 已联系 / 已合作）、导出 Excel；有新留资时提醒
8. 数据统计与账号权限
  • 积分发放 / 消耗、三大板块分布、商户排行、活动参与情况
  • 多个后台账号，按角色分权限，关键操作留日志
